# Helix desktop installers

Sign in at [app.helix-cx.com](https://app.helix-cx.com).

Prebuilt desktop installers for Helix are published on this repository’s [Releases](https://github.com/helix-cx/helix-desktop-releases/releases) page.

The current preview is macOS Apple Silicon only (macOS 14.4+). Windows and Linux builds will follow.
